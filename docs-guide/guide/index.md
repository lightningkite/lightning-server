# Lightning Server

Lightning Server is a Kotlin server framework for building production backends faster.
Define typed endpoints, service settings, and authentication rules in plain Kotlin; the
framework handles HTTP routing, SDK generation, unit testing (no running server required),
and derives your complete AWS Terraform infrastructure from the same server definition.

**Status:** pre-release (version 5). The API is settling and breaking changes are still possible.
